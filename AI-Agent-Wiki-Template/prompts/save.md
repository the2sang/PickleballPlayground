# Save Prompt

```text
이번 작업 내용을 옵시디언에 save 해줘.

먼저 CLAUDE.md와 AGENTS.md의 저장 규칙을 확인하고, 아래 5가지 저장 필터를 적용해줘.

1. 향후 실무에 반복해서 재사용될 데이터인가?
2. 다른 에이전트나 동료가 프로젝트를 이어받기 위해 반드시 읽어야 하는가?
3. 의사결정의 근거와 결정권자를 나중에 추적할 필요가 있는가?
4. 실패한 방식이라 다시 시도하면 안 되는 리스크 정보인가?
5. 팀 전체가 맞추어야 하는 공통 규칙이나 디자인 가이드인가?

저장할 가치가 있으면 적절한 wiki 카테고리나 conversations 위치를 판단해서 문서를 만들고, 관련 문서끼리 wikilink로 연결해줘.

중요 문서를 만들거나 갱신했다면 index.md와 log.md도 함께 갱신해줘.

저장할 가치가 없으면 저장하지 말고 그 이유를 짧게 설명해줘.
```
