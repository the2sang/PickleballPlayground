# Ingest Prompt

```text
AI-Sessions/raw/에 추가된 자료를 ingest 해줘.

raw 원본은 절대 수정하지 말고, 내용을 읽은 뒤 AI-Sessions/wiki/sources/에 source 요약 문서를 만들어줘.

반복해서 쓸 개념은 wiki/concepts/에, 의사결정은 wiki/decisions/에, 실패와 리스크는 wiki/errors/에, 프로젝트 맥락은 wiki/projects/에 연결해줘.

새 정보가 기존 wiki 문서와 충돌하면 기존 내용을 조용히 덮어쓰지 말고 충돌, superseded 상태, 확인 필요 사항을 명시해줘.

작업이 끝나면 index.md와 log.md를 갱신해줘.
```
