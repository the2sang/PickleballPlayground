EASE_FLOOR    = 1.3
INITIAL_EASE  = 2.5

  ease:          Float,                       # current EF, will be clamped to >= EASE_FLOOR
  interval_days: Integer,                     # current interval
  repetitions:   Integer,                     # current successful-rep count (PRE-increment value)
  rating:        Integer,                     # 1..4 — raises ArgumentError otherwise

) #=> Result(ease:, interval_days:, repetitions:, next_review_at:)

# Algorithm (SM-2, public domain):
#   q = QUALITY_MAP[rating]
#   new_ease = [ease + (0.1 - (5 - q) * (0.08 + (5 - q) * 0.02)), EASE_FLOOR].max
#   if q < 3   then new_reps = 0;          new_interval = 1
#   else            new_reps = reps + 1
#                   new_interval = case reps              # NB: pre-increment value
#                                  when 0 then 1
#                                  when 1 then 6
#                                  else (interval * new_ease).round
#                                  end
#   end
#   Result.new(ease: new_ease.round(2), interval_days: new_interval, repetitions: new_reps,

## Trust Boundaries (Phase 1 scope)

Phase 1 has **no HTTP surface** — it adds only models, services, schema, factories, seed loader, and policy stubs. The only trust boundary present is in the SM-2 service constructor (Phase 3 will eventually feed it controller params).

| Boundary | Description |
|----------|-------------|
| seed loader → DB | Repo-controlled YAML, no external input. Trust = HIGH. |
| SM-2 service `rating:` arg | Future Phase 3 controller will pass user-provided rating. Service treats it as untrusted. |
| ForkDeckService `source:` arg | Future Phase 4 controller will pass a Deck record. Service trusts caller to have authorized the source; no internal auth check (correct separation). |
