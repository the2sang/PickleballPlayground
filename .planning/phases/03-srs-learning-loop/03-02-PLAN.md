**컨트롤러** (`app/controllers/card_reviews_controller.rb`):

`class CardReviewsController < ApplicationController` (네임스페이스 없음, 최상위). 인증은 `Authentication` concern으로 자동 (A2).

`#create` 흐름:
1. `@card = Card.find(params[:card_review][:card_id])` — 비정상 ID는 RecordNotFound (Rails 기본 404).
2. **`@card_review = CardReview.new(user: Current.user, card: @card)`** — 이 시점에 record.user = current.user 보장.
3. **`authorize @card_review`** (또는 `authorize @card_review, :create?`) — CardReviewPolicy#create?가 `record.user == user` 검증 (T-03-01 방어). 타 사용자 카드 평가 시도는 여기서 차단되어 `Pundit::NotAuthorizedError` → ApplicationController의 `user_not_authorized`로 root_path 리다이렉트.
4. `rating = params[:card_review][:rating].to_i`. SubmitReviewService 내부 SM2Service가 VALID_RATINGS로 ArgumentError raise(T-03-02 방어). 컨트롤러는 `rescue ArgumentError` 추가하여 `head :unprocessable_entity` 또는 error partial 렌더.
5. `result = Flashcards::SubmitReviewService.call(user: Current.user, card_id: @card.id, rating: rating)`.
6. `@deck = Deck.find(params[:card_review][:deck_id]) if params[:card_review][:deck_id].present?` — 글로벌 큐 호출 시 nil 허용(미래 확장; 지금은 항상 deck_id 전달 가정). Deck.find은 deck_id 위조 시 NotFound로 차단 + 명시 `authorize @deck, :show?` 호출(T-03-03 방어).
7. 성공 경로: `@next_card = @deck ? Flashcards::StudyQueueQuery.new(user: Current.user, deck: @deck).call.first : nil` → `respond_to { |f| f.turbo_stream }` (자동으로 `create.turbo_stream.erb` 렌더).
8. 실패 경로 (`result.success? == false`): `flash.now[:alert] = result.errors.join(", ")` 후 `respond_to { |f| f.turbo_stream { render :error, status: :unprocessable_entity } }`.

private `card_review_params` — `params.require(:card_review).permit(:card_id, :rating, :deck_id)`. **`front_image`/`back_image` 절대 permit 금지 (D-20)** — 본 컨트롤러에서는 그 필드 자체가 의미 없지만 명시 주석으로 남길 것.

require "rails_helper"

RSpec.describe "CardReviews", type: :request do
  let(:user)    { create(:user) }
  let(:other)   { create(:user) }
  let(:deck)    { create(:deck, :personal, owner: user) }
  let(:card)    { create(:card, deck: deck) }

  describe "POST /card_reviews" do
    context "인증된 본인 덱 카드 평가" do
      before { sign_in(user) }

      it "rating=3 평가 시 CardReview를 생성하고 Turbo Stream으로 응답한다" do
        expect {
          post card_reviews_path,
            params: { card_review: { card_id: card.id, deck_id: deck.id, rating: 3 } },
            headers: headers
        }.to change(CardReview, :count).by(1)
        expect(response).to have_http_status(:ok)
        expect(response.media_type).to eq("text/vnd.turbo-stream.html")
        expect(response.body).to include("study-card")
      end

      it "Turbo Stream으로 #study-card를 다음 카드 또는 complete partial로 replace한다" do
        # 추가 카드 없으면 complete 렌더 검증
        post card_reviews_path, params: { card_review: { card_id: card.id, deck_id: deck.id, rating: 3 } }, headers: headers
        expect(response.body).to include("turbo-stream").and include("study-card")
        expect(response.body).to include("오늘의 학습 완료")  # complete partial
      end

      it "두 번째 due 카드가 있으면 _card partial로 replace" do
        next_card = create(:card, deck: deck, position: 2)
        post card_reviews_path, params: { card_review: { card_id: card.id, deck_id: deck.id, rating: 3 } }, headers: headers
        expect(response.body).to include("turbo-stream")
        expect(response.body).not_to include("오늘의 학습 완료")
      end

      it "동일 카드 더블 submit 시 단일 CardReview 만 유지 (멱등성)" do
        2.times do
          post card_reviews_path, params: { card_review: { card_id: card.id, deck_id: deck.id, rating: 3 } }, headers: headers
        end
        expect(CardReview.where(user: user, card: card).count).to eq(1)
      end

      it "out-of-range rating (5)은 422 응답 (T-03-02)" do
        post card_reviews_path, params: { card_review: { card_id: card.id, deck_id: deck.id, rating: 5 } }, headers: headers
        expect(response).to have_http_status(:unprocessable_entity).or have_http_status(:bad_request)
      end
    end

    context "타 사용자 카드 평가 시도 (T-03-01)" do

        expect(response).to redirect_to(root_path).or have_http_status(:forbidden)

        expect(response).to redirect_to(new_session_path)
      end
    end
  end
end

```javascript
import { Controller } from "@hotwired/stimulus"

export default class extends Controller {
  static targets = ["back", "showButton", "ratingRow", "keyHints", "ratingButton", "divider"]

  connect() {
    this.flipped = false
    this.handleKeydown = this.handleKeydown.bind(this)
    document.addEventListener("keydown", this.handleKeydown)
  }

  disconnect() {
    document.removeEventListener("keydown", this.handleKeydown)
  }

  flip(event) {
    if (event) event.preventDefault()
    this.flipped = true
    this.showButtonTarget.classList.add("hidden")
    this.showButtonTarget.setAttribute("aria-expanded", "true")
    this.backTarget.classList.remove("hidden")
    this.ratingRowTarget.classList.remove("hidden")
    if (this.hasKeyHintsTarget) this.keyHintsTarget.classList.remove("hidden")
    if (this.hasDividerTarget) this.dividerTarget.classList.remove("hidden")
  }

  submitRating(event) {
    // 더블클릭 가드 (D-05): 모든 평가 버튼을 즉시 disable. Turbo Stream replace 후 새 partial이 unflipped 초기 상태로 mount되므로 수동 re-enable 불필요 (Pitfall 4).
    this.ratingButtonTargets.forEach(btn => {
      btn.disabled = true
      btn.setAttribute("aria-disabled", "true")
    })
    // form submission은 button[type=submit]이 자동으로 처리 — preventDefault 금지
  }

  handleKeydown(event) {
    if (!this.flipped) return  // D-04: flip 전 키 입력 차단 (Pitfall 3)
    const map = { "1": 0, "2": 1, "3": 2, "4": 3 }
    const idx = map[event.key]
    if (idx !== undefined && !event.metaKey && !event.ctrlKey && !event.altKey) {
      event.preventDefault()
      this.ratingButtonTargets[idx]?.click()
    }
  }
}
```

> `static values`는 사용하지 않음 — flip 상태는 인스턴스 변수 `this.flipped`로 충분 (각 카드 마운트마다 신선한 controller 인스턴스가 생성됨).

기존 importmap/`index.js`는 Stimulus가 자동 등록(`eagerLoadControllersFrom("controllers", application)`)이라면 추가 wiring 불필요. `app/javascript/controllers/index.js` 확인 후 명시 등록이 필요한 패턴이라면 (`application.register("study-session", StudySessionController)`) 1줄 추가.
